# Report the independent validations, including what failed

## What to build

The section this whole cycle exists to make possible: the independent evidence, with its outcomes,
whatever they turned out to be.

A run in which every prediction was confirmed should read as suspicious rather than triumphant, so
effect sizes and arm sizes are reported throughout and the registered predictions sit next to the
results.

## Acceptance criteria

- [ ] Every pre-specified test is reported with its effect size and adjusted p-value, including failures and contradictions
- [ ] The registered predictions are reproduced next to the outcomes, so a reader sees what was expected before it was known
- [ ] A module that failed to replicate keeps its place in the map, with the failure stated and the confounds that would need excluding
- [ ] Analyses labelled corroboration are not presented as validation anywhere in the section
- [ ] The internal consistency check is not presented as independent evidence
- [ ] Any analysis added after seeing results is labelled post-hoc and reported after the pre-specified ones
- [ ] Every number passes the stale-number guard
