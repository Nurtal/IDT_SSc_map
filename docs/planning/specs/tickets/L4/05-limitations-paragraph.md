# Place the calibrated Limitations paragraph

## What to build

One paragraph carries every honest limitation of the resource, stated factually and once.

## Acceptance criteria

- [ ] The paragraph states: no independent expert ratification to date; modules as an expert-defined reading frame; coverage as corroboration rather than validation; bulk data cannot separate composition shift from module activation; no clinical stratification is possible from the public deposits
- [ ] None of these statements is repeated elsewhere in the manuscript
- [ ] The register is factual and unapologetic: the limits are stated, not performed
- [ ] Each limitation names what would resolve it, where something would
